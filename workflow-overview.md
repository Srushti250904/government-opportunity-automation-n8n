# Workflow Overview

## Government Opportunity Automation

This project explores an automated workflow for discovering and processing government contracting opportunities.

### Workflow Components
- Scheduled execution
- Government opportunity API integration
- Data parsing and filtering
- AI-assisted opportunity classification
- Duplicate handling
- Google Sheets data management

### Technologies
- n8n
- REST APIs
- JavaScript
- OpenAI API
- Google Sheets

### Learning Outcomes
- Workflow orchestration
- API integration and data transformation
- AI-assisted classification
- Conditional logic and error handling
- Automation design and debugging
